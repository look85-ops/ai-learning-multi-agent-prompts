# AI Learning Multi-Agent Prompts

Пять ролей для последовательного проектирования одной образовательной задачи.

```text
brief -> learning_spec -> draft -> critique -> evaluated_result
```

## Как работать

1. Передай исходный запрос Аналитику задачи.
2. Передай его brief Методисту.
3. Передай learning_spec Автору сценария.
4. Передай draft Критику.
5. Передай draft и critique Eval Owner.
6. Человеку покажи результат, доказательства, ограничения и вопросы для решения.

Каждая роль содержит границы и формат передачи следующему этапу. Роли можно запускать по очереди в одном чате или разнести по отдельным агентам.
